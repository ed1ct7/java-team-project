# Java team project

College group project (MDK course, group 326). Every team member implemented
their own classes in `src/main/java/allclasses/<surname>/` — entities and
repository-pattern data access, e.g. `Toy`, `Vector`, `Straight`, `Coffee`,
`Animal`, `Rectangle`, school entities with repositories — plus a shared
`Main.java` entry point.

Maven project: build with `mvn package` or open in your IDE.
